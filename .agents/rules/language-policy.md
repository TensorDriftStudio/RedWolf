# Language Policy: English Only

## Absolute Requirement
Polish or any language other than English is **strictly forbidden** across the entire RedWolf project.

1. **Code & Comments:** All code, comments, docstrings, variable names, and error strings must be written in English.
2. **Documentation & Assets:** All markdown files, guides, specifications, and web UI templates must be written in English.
3. **Git History:** All commit messages, branches, and PRs must be written in English.
4. **AI Assistant Communications:** All explanations, responses, and planning generated by AI models must be delivered in English.
